# Basic Rule-Based Chatbot

A simple command-line chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

## Description

This project is a rule-based chatbot that responds to simple user messages. It uses predefined responses and does not use any external libraries or APIs.

The chatbot can respond to greetings, answer basic questions, provide help, and end the conversation when the user types `bye`, `goodbye`, or `exit`.

## Features

- Responds to greetings such as `hello`, `hi`, and `hey`
- Responds to `how are you`
- Answers questions about its name
- Provides a help message
- Handles unknown messages
- Ends the chat when the user types `bye`, `goodbye`, or `exit`
- Uses functions, conditional statements, loops, and input/output

## Technologies Used

- Python 3
- No external libraries required
